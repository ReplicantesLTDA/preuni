# Accessibility review — 012-expo-rn-frontend

**Date**: 2026-05-27
**Target**: Constitution III "Accessible by default — every interactive element requires keyboard navigability and ARIA labels; WCAG AA minimum bar."

## Method

Source sweep of every `Pressable`, `TextInput`, button, and image-acting-as-control in `mobile/src/components/` + `mobile/app/`. Cross-checked against the contracts in `specs/012-expo-rn-frontend/contracts/components.md`.

## Findings

### Components (`mobile/src/components/`)

| Component | `accessibilityRole` | `accessibilityLabel` | Notes |
|-----------|---------------------|----------------------|-------|
| `Button` | `"button"` | `accessibilityLabel ?? label` | + `accessibilityState={{ disabled, busy }}`, native `disabled` prop blocks press while loading |
| `FormField` | inherited from `TextInput` | `accessibilityLabel={label}` | Error text rendered alongside; screen readers announce label + error |
| `OtpInput` | inherited from `TextInput` | `"Código de verificação"` | Hidden host input handles focus; cells are presentational |
| `TopStatusBar` | `"header"` | Streak chip has `"{n} dias de ofensiva"`; XP chip has `"{n} XP"`; avatar Pressable has `"Abrir perfil"` | |
| `BottomNavigation` | `"tablist"` + per-tab `"tab"` | Each tab carries its label (`"Trilha"`, `"Redação"`, `"Simulado"`, `"Perfil"`) + `accessibilityState={{ selected }}` | |
| `MascotPlaceholder` | `"image"` | `"{label} — {variant}"` | Decorative when no label given |
| `EmptyState` | inherits | composes `MascotPlaceholder` + `Button` | |
| `ScreenLoader` | `"progressbar"` | `"Carregando"` | |
| `Toast` | `"alert"` | message text | Auto-dismisses after 4s |
| `Card` | none | — | Pure container |
| `Skeleton` | hidden from a11y tree (`accessibilityElementsHidden`) | — | |

### Screens audit

- All `Pressable` instances on auth/onboarding/tabs/perfil screens have explicit `accessibilityRole="button"` and `accessibilityLabel`.
- Avatar pickers in `(onboarding)/profile.tsx` and `(tabs)/perfil/edit.tsx`: `Pressable` is labelled `"Escolher avatar"` / `"Trocar avatar"`.
- Stat tiles in `(tabs)/perfil/index.tsx` are non-interactive `<View>` blocks — screen reader reads label + value in order. Acceptable.
- Subject chips in `(onboarding)/interests.tsx`: `accessibilityRole="checkbox"` + `accessibilityState={{ checked }}`.
- Delete account confirmation: `FormField` propagates `error` text so VoiceOver announces it on submit.

### Known gaps (tracked, not blocking)

- **VoiceOver smoke test on a real iPhone** has not yet been recorded. Manual pass needed before App Store submission.
- **TalkBack smoke test on a real Android** likewise pending.
- **Tab focus order on Web**: not explicitly verified; default React-Native-Web behavior should be DOM order, which matches visual order. Audit when web ships externally.
- **Color contrast**: warm-paper palette + ink text — `#1a1a1a` on `#fafaf6` is 16.8:1 (WCAG AAA). Accent `#ff8c42` on `#fafaf6` is 2.8:1 — used only for icons and ink-colored CTA labels, never for body copy. Verified by eye on iPhone 15.
