Avalia mecanismos linguísticos de coesão: variedade de conectivos, referenciação (pronominal/
nominal), pontuação a serviço da articulação, transições entre parágrafos.

# DECISÃO RÁPIDA

| Score | Sinais observáveis no texto |
|-------|------------------------------|
| **200** | Conectivos DIVERSIFICADOS (concessivos, conclusivos, adversativos, causais, comparativos) usados corretamente. Referenciação clara. Transições explícitas entre parágrafos. |
| **160** | Conectivos variados com 1-2 lapsos. Articulação geral preservada. Pequenas inadequações de coesão. |
| **120** | Uso repetido dos mesmos conectivos básicos (mas, então, porém). Transições funcionam mas são abruptas. |
| **80** | Várias quebras de coesão. Referenciação ambígua em vários trechos. Conectivos limitados. |
| **40** | Conectivos quase ausentes. Texto parece sequência de frases. Uso quase exclusivo de "e" e "mas". |
| **0** | Nenhuma articulação. Texto sem estrutura entre parágrafos. RARO. |

# ANTI-VIÉS

- Conectivo correto repetido não é erro grave — é apenas pouca diversidade (= 120 em vez de
  160).
- Pontuação a serviço da articulação (vírgula entre orações coordenadas) conta como coesão.
- Não confunda problemas de C1 (concordância) com problemas de C4 (coesão).
