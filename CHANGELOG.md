## [0.1.0] - 2026-04-03

### Features
- Bootstrap Sprint 1: auth (login, register, OTP), onboarding, home screen, user management
- KMP shared module with Compose Multiplatform (Android, iOS, Web/Wasm)
- Go microservices: auth-svc, user-svc with GDPR-compliant account deletion
- Elixir mail service with Swoosh for transactional emails
- NGINX API gateway with JWT validation and rate limiting
- PostgreSQL migrations for auth and user schemas
