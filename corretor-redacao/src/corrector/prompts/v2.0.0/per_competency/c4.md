# Avaliação focada — Competência 4

**Mecanismos linguísticos para a construção da argumentação (coesão)**

Avalia: variedade de conectivos, referenciação (pronominal/nominal), pontuação a serviço da
articulação, transições entre parágrafos. Apenas esses aspectos. NÃO avalie norma culta
(C1) — concordância e regência são problemas de C1, não C4.

# DECISÃO RÁPIDA

| Score | Sinais observáveis |
|-------|---------------------|
| **200** | Conectivos DIVERSIFICADOS (concessivos, conclusivos, adversativos, causais, comparativos) usados corretamente. Referenciação clara. Transições explícitas entre parágrafos. |
| **160** | Conectivos variados com 1-2 lapsos. Articulação geral preservada. |
| **120** | Uso repetido dos mesmos conectivos básicos (mas, então, porém). Transições funcionais mas abruptas. |
| **80** | Várias quebras de coesão. Referenciação ambígua em vários trechos. Conectivos limitados. |
| **40** | Conectivos quase ausentes. Texto parece sequência de frases. Uso quase exclusivo de "e" e "mas". |
| **0** | Nenhuma articulação. Texto sem estrutura entre parágrafos. RARO. |

# ÂNCORAS

**200 (nota 1000)**: usa "Com a intensa globalização", "Além disso", "Por outro lado",
"Portanto", "É visível, ainda" — leque variado e correto. Referenciação clara.

**160 (nota 880)**: usa "Primeiramente", "Desse modo", "Ademais" — variação boa com pequenos
lapsos.

**120 (nota 560)**: usa "Entretanto", "Em contradição", "Diante dessa" — funcional mas
repetitivo.

**80 (nota 400)**: uso quase exclusivo de "e", "mas", "então" — articulação pobre.

# ANTI-VIESES

- **Conectivo correto repetido ≠ erro grave** — apenas pouca diversidade (= 120 em vez de 160).
- **Pontuação a serviço da articulação** (vírgula entre orações coordenadas) conta como coesão.
- **NÃO confunda problemas de C1 (concordância) com C4 (coesão)**. Avalie só coesão aqui.
