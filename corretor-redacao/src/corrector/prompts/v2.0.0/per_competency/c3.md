# Avaliação focada — Competência 3

**Seleção, relação, organização e interpretação de informações em defesa de um ponto de vista**

Avalia: existe um projeto argumentativo? Argumentos progridem? Há autoria? Tese é defendida com
consistência? Apenas esses aspectos. NÃO avalie norma culta, coesão, ou proposta aqui.

# DECISÃO RÁPIDA

| Score | Sinais observáveis |
|-------|---------------------|
| **200** | Tese explícita. Cada parágrafo de desenvolvimento defende UM argumento distinto e complementar. Conexão lógica entre argumentos e tese. AUTORIA evidente (interpretação própria, não só fatos). |
| **160** | Tese clara. Argumentos relacionados ao tema, organizados, mas com articulação interna menor. Indícios de autoria. |
| **120** | Tese mantida. Argumentos limitados aos textos motivadores. Pouca progressão entre parágrafos. |
| **80** | Argumentos pouco relacionados ao tema OU contraditórios OU repetitivos. Tese inconsistente. |
| **40** | Tese ausente ou apenas sugerida. Argumentos soltos sem encadeamento. |
| **0** | Nenhuma defesa de ponto de vista identificável. Geralmente acompanha critério eliminatório. |

# ÂNCORAS

**200 (nota 1000)**: tese explícita ("a obesidade deve ser combatida com medidas positivas").
Cada parágrafo defende um aspecto distinto (mudanças comportamentais; disponibilidade de
alimentos processados). Interpretação própria dos dados citados.

**160 (nota 880)**: dois argumentos articulados (cultura dinâmica; preservação histórica).
Autoria reconhecível mas com menos profundidade que 200.

**120 (nota 560)**: tese reconhecível, argumentos limitados aos motivadores.

**80 (nota 400)**: argumentos vagos e tangenciais.

# ANTI-VIESES

- **Argumentação previsível ainda é argumentação** — não dê 40.
- **Posição contrária à corrente é VÁLIDA**. Avalie a defesa.
- **Repertório do motivador USADO para argumentar = autoria**. Só citar sem usar = nível baixo.
- **Não desconte por "falta de originalidade"** quando tese é consistente.
