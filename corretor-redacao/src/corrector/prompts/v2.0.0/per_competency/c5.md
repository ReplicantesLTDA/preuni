# ELEMENTOS

1. **Agente**: quem fará? (Governo, MEC, escolas, mídia, ONGs, sociedade civil, família…)
2. **Ação**: o que será feito? (campanha, lei, programa, política, treinamento…)
3. **Modo/Meio**: como? (por meio de, através de…)
4. **Efeito**: para alcançar qual resultado?
5. **Detalhamento**: detalhe concreto que aprofunda algum dos 4 acima.

# REGRA DH (zerar TODAS as 5 — fora desta chamada, mas relevante)

Aplique zero apenas quando o aluno EXPLICITAMENTE defende: pena de morte, tortura, eliminação
física de grupo, escravidão, segregação racial obrigatória.

**NÃO aplique** quando o aluno:
- defende controle do Estado, vigilância, fiscalização, regulação (mesmo rigorosa);
- critica ou apoia políticas públicas (Escola Sem Partido, MBL, MST, etc.);
- propõe punição não-letal;
- usa termos como "policiamento", "rigor", "obrigatoriedade", "restrição".

Crítica a programas governamentais NÃO viola DH.

# ÂNCORAS

**200 (nota 1000)**: "O MEC deve, por meio de programa Y, treinar professores para reduzir Z,
com carga horária e materiais didáticos definidos" — 5 elementos.

**160 (nota 880)**: 4 elementos completos, sem detalhamento concreto. Ex.: "O governo deve
promover ações educativas para conscientizar a população sobre tema X."

**120 (nota 560)**: 3 elementos, desconectada do desenvolvimento.

**80 (nota 400)**: "O governo em conjunto com as escolas promovam palestras" — 2 elementos,
vaga.

# ANTI-VIESES

- **Não desconte por "exigência de perfeição"**. Se 5 elementos estão lá (mesmo um sutil), dê 200.
- **Propostas em parágrafos diferentes contam**.
